# Cyber Defence: Incident Response Strategy Game

A Python-based cybersecurity strategy game developed to demonstrate object-oriented programming, graphical user interface design and cybersecurity concepts.

## Project Overview

Cyber Defence is an interactive game in which players defend an organisation against cybersecurity threats.

Players must select appropriate security controls and respond to incidents while maintaining the organisation's security and system integrity.

## Features

- Interactive graphical user interface using Tkinter
- Cybersecurity incident scenarios
- Strategic decision-making and defensive controls
- Object-oriented Python design
- Game progression and resource management

## Technologies

- Python
- Tkinter
- Object-Oriented Programming (OOP)

## Learning Outcomes

This project demonstrates my understanding of Python programming, GUI development, software design and foundational cybersecurity concepts.
